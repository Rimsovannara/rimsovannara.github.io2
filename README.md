## 🖥️ Running Locally

No build step required — just clone and open.

```bash
git clone https://github.com/Rimsovannara/rimsovannara.github.io.git
cd rimsovannara.github.io
# Open index.html in your browser
start index.html   # Windows
open index.html    # macOS
```

Or use any local static server:

```bash
npx serve .
```
